# Evidencias

Esta carpeta contiene las evidencias de las pruebas realizadas sobre SauceDemo.

Las evidencias incluyen capturas correspondientes a:

1. Inicio de sesión.
2. Validación de acceso.
3. Catálogo.
4. Adición al carrito.
5. Consulta del carrito.
6. Eliminación de productos.
7. Checkout.
8. Finalización de compra.
9. Validaciones.
10. Automatización.
